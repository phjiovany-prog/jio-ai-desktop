# Jio AI for Desktop — downloads

This repository only holds the installer files for Jio AI for Desktop. Get the app from
**https://askjio.app/download**, where you'll also find install steps and each file's SHA-256 checksum.

- Windows 10 or later (x64).
- Version 0.1.0 isn't signed with a paid certificate yet, so Windows shows "Windows protected your PC"
  before installing. Only run installers you downloaded from askjio.app/download or this page's
  Releases, and check the checksum if you like.

Jio AI is created by Jio.
